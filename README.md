# یادمان

اپ اندرویدی که پیامک‌هایت با یک نفر را می‌خواند و از سال‌ها گفتگو یک خط زمان می‌سازد.
همه‌چیز روی خود گوشی و بدون اینترنت انجام می‌شود (اپ اصلاً اجازه‌ی INTERNET ندارد).

## چه چیزی نشان می‌دهد

- **خلاصه‌ی کلی:** طول رفاقت، تعداد پیام‌ها، سهم هر کدامتان، روزهای پشت‌سرهم، شلوغ‌ترین روز،
  طولانی‌ترین سکوت، کی بیشتر سر صحبت را باز می‌کند، سرعت جواب دادن، ساعت و روز محبوب،
  ایموجی‌ها و کلمه‌های همیشگی، و اولین پیام.
- **نمودار ماه‌به‌ماه** پیام‌های تو و او.
- **امروز در سال‌های قبل:** پیام‌هایی که در همین روز شمسی در سال‌های گذشته رد و بدل شده‌اند.
- **خط زمان فصل‌به‌فصل** (یا ماه‌به‌ماه اگر رابطه کمتر از ۱۸ ماه باشد). برای هر فصل:
  - کلمه‌های کلیدی همان دوره (TF-IDF: کلمه‌هایی که آن موقع زیاد گفتید و بعداً نه)
  - رویدادها: تولد، تسلیت، عید، عروسی، قبولی، مهاجرت، سربازی، کار، بیمارستان، اسباب‌کشی، سفر، دلخوری و آشتی، تبریک
  - چند پیام شاخص همان دوره
  - دکمه‌ی دیدن همه‌ی پیام‌های آن دوره
  - دوره‌های سکوت بیش از ۴۵ روز بین فصل‌ها

## ساختن و نصب

1. [Android Studio](https://developer.android.com/studio) را نصب کن (JDK و Android SDK همراهش هست).
2. این پوشه را با **File › Open** باز کن و صبر کن Gradle Sync تمام شود.
   - اگر Sync با خطای 403 یا قطعی دانلود از `dl.google.com` یا `maven.google.com` شکست خورد،
     یعنی دسترسی به مخزن گوگل برقرار نیست و باید از راه دیگری (مثلاً پراکسی یا میرور) وصل شوی.
3. گوشی را با کابل وصل کن و **USB debugging** را از Developer options روشن کن، بعد دکمه‌ی ▶ Run.
   یا از منوی **Build › Build App Bundle(s) / APK(s) › Build APK(s)** فایل APK بساز و روی گوشی نصب کن.

کمترین نسخه‌ی اندروید: ۸ (API 26). روی سامسونگ، شیائومی، هوآوی (حتی بدون سرویس‌های گوگل) و بقیه کار می‌کند.

### نکته‌های گوشی‌ها

- **شیائومی (MIUI / HyperOS):** اگر بعد از دادن اجازه پیامی نیامد، در تنظیمات اپ › Permissions،
  «پیامک» و «خواندن پیامک‌های اعلان / Notification SMS» را روشن کن.
- **گوگل‌پلی:** گوگل اپ‌هایی که پیامک می‌خوانند را فقط اگر اپ پیش‌فرض پیامک باشند منتشر می‌کند؛
  برای استفاده‌ی شخصی APK را مستقیم نصب کن.
- پیام‌های **RCS** (چت گوگل مسیج) و **MMS** (پیام گروهی و عکس) در این نسخه خوانده نمی‌شوند.

## ساختار کد

| مسیر | کار |
| --- | --- |
| `app/src/main/java/com/yadman/app/analysis/` | موتور تحلیل، بدون وابستگی به اندروید: یکسان‌سازی متن فارسی، کلمه‌های بی‌اهمیت، تقویم شمسی، تشخیص رویداد، ساخت خط زمان |
| `app/src/main/java/com/yadman/app/data/` | خواندن پیامک‌ها و اسم مخاطب‌ها، یکسان‌سازی شماره‌ها |
| `app/src/main/java/com/yadman/app/ui/` | صفحه‌ها با Jetpack Compose |
| `app/src/test/` | تست‌های موتور تحلیل (در Android Studio: کلیک راست روی پوشه › Run Tests) |

## قدم‌های بعدی

- خلاصه‌ی نوشتاری هر فصل با یک مدل زبانی آفلاین (مثل Gemma) روی گوشی‌هایی که رم کافی دارند.
  مدل فقط پیام‌های شاخصی را می‌خواند که این نسخه برای هر فصل انتخاب کرده است.
